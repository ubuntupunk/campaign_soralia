# Campaign Roles

This directory describes the roles used to triage and respond to input from the Soralia Village Campaign. The campaign supports seniors, disabled persons, and military veterans affected by unlawful HOA handovers and charges.

## Roles

| Role | File | Primary focus |
|------|------|---------------|
| Campaign Chief | `campaign-chief.md` | Strategy, final decisions, public position |
| General Organiser | `general-organiser.md` | Operations, coordination, petition list |
| David's Assistant | `davids-assistant.md` | David's personal correspondence and scheduling |
| Welfare Liaison | `welfare-liaison.md` | Seniors, disabled persons, veterans support |
| Communications Officer | `communications-officer.md` | Emails, petitions, website, public messaging |
| Legal Officer | `legal-officer.md` | CSOS, CDC, Constitution, legal queries |
| Triage Officer | `triage-officer.md` | Reviewing and routing all incoming input |

## How triage works

1. **Triage Officer** receives all incoming input (petition form, email, phone, in-person)
2. Each item is **logged, categorised, and prioritised**
3. The item is **routed** to the role holder best placed to respond:
   - Legal/CSOS/constitutional → Legal Officer
   - Welfare/help (seniors, disabled, veterans) → Welfare Liaison
   - Personal to David → David's Assistant
   - Campaign operations → General Organiser
   - Communications/email/petitions → Communications Officer
4. Escalations affecting campaign position or reputation go to the **Campaign Chief**

## Privacy

No member personal data is committed to this repository. Case registers, send logs, and recipient lists are kept locally and gitignored.
